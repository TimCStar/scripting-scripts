# 验证记录

日期：2026-10-10（Asia/Shanghai），脚本 1.2.0。Node 24.14.0，TypeScript 5.9.3，fflate 0.8.3。

## 已验证

- 39 项自动测试通过：原有日期、金额、分页、编辑、排序与生命周期回归，10 项图标读取和缓存测试，4 项中文分类／汇率测试，以及 3 项登录表单回归。
- 登录输入：使用官方 `SecureField`，邮箱下方直接显示密码框，登录不再调用密码 Dialog。模拟登录验证密码保留空格且只进入 HTTPS 登录请求、不进入 Storage / Keychain；缺少密码不发请求；失败、提交、切换模式与离开页面会清空已提交或输入的密码。用户提供站点的匿名状态接口响应正常，返回 Turnstile 未启用；没有使用用户账号发送登录请求。
- 图标补充：同站绝对资产地址鉴权、相似域名不带凭证、匿名重定向清空 Cookie 与次数上限、静态 SVG 样式转绘图属性、白色图形使用深底、ChatGPT 离线图标。
- 展示数据：中文内置／自定义分类、编辑保留后台值、未知分类保留、连接隔离与断开后的在途配置丢弃；USD 基准交叉汇率、两位小数、未知币种不虚构报价、匿名备用源、24 小时缓存与断网保留源日期。
- 图标：保留上游 `logo` 字段，协议／路径校验，子路径私有资产与会话过期，外部请求不带凭证，静态 SVG 与位图解码分流，重复请求合并、离线读取、身份隔离、容量上限、断开连接后的在途请求不能回填缓存、无效／超大／不安全内容首字占位、后台加载不占用列表刷新锁。位图解码测试使用 host 模拟对象，未验证设备编解码器。
- 客户端：游标分页、ID 去重、重复游标失败、响应格式校验、只读 Token 禁写、Session / CSRF / Origin、ID 编码、超时配置与拒绝重定向、会话过期、固定错误文案、Cookie 提取与两阶段 MFA 契约。
- 模拟 Scripting host：三种组件入口与详情／全部链接，原生页面入口、全部订阅数量与退出，演示编辑与添加、本机重置、站点凭证隔离、网络失败保持旧时间、配置切换丢弃旧缓存、其他设备修改拒绝 PATCH、旧列表请求不能覆盖确认后的写入、页面离开后重新出现不遗留刷新锁。
- 对所有运行时 `.ts`／`.tsx` 做 TypeScript 语法诊断；对 `model.ts`、`client.ts`、`presentation.ts` 做 `tsc --strict --noEmit`。
- Playwright 在实际 TSX 生成的 HTML 近似中检查 light / dark 的 155×155、329×155、329×345 尺寸；文本和图标边界未超出容器；三种尺寸均包含外币换算，长短名称混合，中／大组件的每行名称与日期均从容器 x=51 px 开始（深浅一致）。名称 VStack 的内部 alignment 与扩展 frame 都明确设为 leading；行高使用合法 flexible frame，不混用固定 height 与 maxWidth。保存 `assets/design-preview.png`。预览渲染实际内嵌演示 SVG，未使用远程品牌图片。修正 HTML 渲染器把横向填充错误应用为纵向增长的问题；这不验证 SwiftUI 字号、系统边距与交互。
- 上游公开演示 `https://demo.renewlet.cc`：使用公开虚构演示账号完成登录、完整列表分页（本次 100 条）、详情读取、退出撤销会话。没有订阅 POST / PATCH / DELETE；会话未写入磁盘。
- 打包后解压逐文件比对，确认 `.scripting` 根目录入口、清单与源码一致，生成 SHA-256。开发依赖审计无已知漏洞。

## 还需真机验证

当前没有连接 iPhone，不具备 app 同步的官方 Scripting `.d.ts`。主屏幕渲染、真实系统点击、iOS 深浅／着色模式、钥匙串可用性、真实服务器写入没有完成端到端验证。

1. 导入后先用虚构演示账本添加／编辑，关闭重开检查排序记忆和演示持久化。
2. 在设置分别预览小、中、大，并真正添加到主屏幕；检查最小设备字号、长名称、较大金额、空列表、旧快照，以及深浅／iOS 着色模式。检查外部 PNG／JPEG、静态 SVG 和登录后的私有上传图标，断网时应保留已缓存图标。
3. 连接自己的站点：只读 Token 读取全部与详情、确认添加／编辑禁用；登录模式确认 Cookie / CSRF、TOTP／恢复码、会话过期与退出。
4. 使用一笔专门的测试订阅验证真实添加和编辑：网页核对金额、周期、日期、提醒，并确认 Logo、家庭分摊、重复提醒与 `extra` 未被清空。
5. 在网页修改同一笔后，再在旧编辑表单保存，确认冲突提示。断网时核对旧快照标记与原成功时间。
6. 对照账户时区验证午夜边界。确认 Turnstile / Passkey 站点按文档使用只读 Token 或网页；这些挑战没有原生登录实现。

## 实现边界

只提供常规订阅表单。家庭成员和收款账本、Logo 上传、公开页面和重复提醒配置通过 Renewlet 网页管理。编辑前检查不能消除检查和 PATCH 之间的所有竞态；上游没有条件写入 ETag 契约。新增遇到响应丢失需刷新确认，没有自动写入重试或客户端幂等键。标价汇总按原币种分开，不是支付确认或个人分摊净额；逐项 CNY 参考换算不是实际扣款价。外部图片不可达时仍需在网页上传为本站图标，未验证用户这两笔订阅的真实图片配置。
