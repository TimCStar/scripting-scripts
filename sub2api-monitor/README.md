# Sub2API 用量看板 · iOS Scripting

一个不依赖第三方中转服务的中文主屏幕小组件与手动重置面板。GPT 用低饱和绿、Claude 用暖橙、Antigravity 用蓝紫；适配浅色/深色。默认首先显示标明「演示 · 虚构数据」的示例，不会联网。

## 安装与配置

1. iPhone 安装 **Scripting**。将 `Sub2API-Monitor.scripting` 用「分享 → Scripting」打开并导入。`.scripting` 是根目录含 `script.json`、`index.tsx`、`widget.tsx` 的 ZIP 包。若系统没有自动识别，在 Scripting 的导入入口选择文件。也可在 app 新建项目，复制源码目录的这几个文件及同目录 `.ts` 模块。
2. 在 Scripting 中运行「Sub2API 用量看板」。填写服务器 HTTPS 地址，例如 `https://sub.example.com`。若部署于子路径，可填 `https://example.com/sub2api`；末尾 `/api/v1` 会自动移除。
3. 填写 Sub2API **上游账号**的数字 ID，以逗号分隔。顺序就是显示顺序，例如 `12,34,56,78`。最多配置 12 个。可以在管理后台查看账号 ID。
4. 选择管理员 API Key（`x-api-key`）或管理员 JWT（`Authorization: Bearer`），在安全输入框粘贴。这里需要管理员权限；普通下游转发 Key、普通用户登录 JWT 不适用。JWT 过期后需要手动更新。本工具不自动登录或刷新凭证。
5. 可先点「测试连接（只读）」，成功后点「保存并启用真实数据」。测试只检查前四个账号，不会保存凭证。保存会清除缓存并请求小组件刷新。
6. 长按主屏幕添加 Scripting 小组件，选择本脚本。小号显示 1 个账号，中号可选 1–2 个，大号可选 1–4 个。可在脚本内分别预览，并切换账号数量选项。
7. 可选：在小组件 Parameter 填已配置的账号 ID，例如 `34` 或 `56,12`，以单独选择/排序及设置数量。中号填 `34` 显示 1 个放大账号，填 `34,12` 显示 2 个；大号可填 1–4 个 ID。参数不得含凭证、URL 或 JSON。未知 ID 或超过此尺寸容量会显示错误，而不会悄悄截断或换账号。留空使用全局配置顺序的前 1 / 2 / 4 个。演示模式可选 101、102、103、104，例如 `101` 看放大 Codex，`101,102` 看双账号。

### 自适应信息密度

- 中号 1 个：放大名称、百分比，并以双栏显示今日费用 / token / 请求数和两个窗口；中号 2 个：紧凑双卡。
- 大号 1 个：放大字体与额度明细；大号 2 个：两张扩展卡；大号 3–4 个：紧凑多行。
- 扩展视图展示每个窗口的绝对重置时间与当前快照计算的倒计时、采样时间、账号状态，以及可选手动参考总额/剩余。倒计时不是后台持续运行的时钟，随 iOS 重绘更新。
- Codex 若已有被动 `codex_reset_credit_snapshot`，大号扩展卡显示缓存的重置券数量/最近到期时间及已有处理状态。该快照没有可靠采样时间，因此始终标明「重置券缓存」；已过期、缺到期记录的正数不当作可用券。不会用另一份自动重置状态的时间冒充券快照时间。影子账号不显示父账号的重置券。
- GPT 扩展卡的「重置…」只打开 Scripting 的重置中心，不会直接操作。演示账号不能执行重置。实际操作必须在应用里再次核对账号、服务器及不可撤销的消耗后确认。

**配置信息仅保存在当前脚本的本地 Storage；凭证仅存本机 Keychain。提供的安装包不包含它们。** 不要分享设备存储备份、真实管理凭证或账号截图。由于管理凭证拥有较大权限，请只在自己的可信设备使用；目前没有假装成「只读」的权限降级。小组件刷新严格限制为三个只读接口；手动重置只在应用内确认后调用下文所列的独立 POST。

## 看板里每个数字的含义

- **原生窗口已用 %**：GPT 读取已有 `codex_5h_*` / `codex_7d_*` 快照；Claude 读取原始会话/7d 快照。Claude 的 0–1 比例换算为百分比。允许显示超过 100%，进度条仅在绘制时封顶。
- **窗口时间**：通常是 5h 和 7d；GPT 若快照声明其他时长，则展示实际时长。不会把未知窗口强行命名成 5h/7d。
- **原生限额**：原生接口通常只提供百分比，未提供可靠的美元或 token 总限额。因此这里只能把 100% 视作该快照的完整额度，不能从当日花费倒推订阅真实上限。
- **估算剩余 %**：`max(0, 100 − 原生已用 %)`。没有测量值时显示「未提供」，绝不当作 0% 已用。
- **可选手动参考金额**：在设置的 JSON 输入框填写，例如 `{"12":{"fiveHour":25,"sevenDay":150}}`。单位 USD。显示的「参考余」= 手动参考金额 × `max(0, 1 − 原生已用比例)`。这是你的参考模型，**并非服务商真实美元限额、余额或承诺**；脚本没有默认填写任何参考金额。非标准时长窗口不会套用 5h/7d 的参考值。留 `{}` 关闭。
- **今日计费 / tok**：来自本 Sub2API 实例的本地 `today-stats.cost` / `tokens`。今日按服务器时区；成本是账号统计口径（可含账号倍率），不是供应商实际收款或订阅余额。实例之外的使用不会计入此金额。
- **重置时间 ↻**：用手机当地时区显示月份/日期与 HH:mm。`待采样` 表示已经到达快照给定的重置点，但尚未证实重新采样；不会自动把已用量归零。相对 reset 秒数只锚定原始采样时间，绝不锚定本次网络请求时间。
- **采样时间 / 旧**：账号行展示可获得的上游采样时间；超过 60 分钟或没有采样时间，窗口标记「旧」。顶部更新时间是本次查询/缓存批次时间，**不等于上游采样时间**。失联时保留旧数据并标记缓存。时间与重置文案仅在系统重绘小组件时更新。
- **Antigravity**：显示账号、分组、平台标识和本地今日用量。当前上游没有持久化的原生额度快照，严格被动模式显示「原生额度：被动接口未提供」。不会把某个模型剩余比例伪装成 5h / 7d。
- **平台图标**：使用离线 SF Symbols 搭配明确的 GPT / Claude / Antigravity 品牌名，分别为几何结、放射形、云朵，是辨识性图示而非官方商标资产。

不对独立账号百分比相加；多分组账号也不会重复计费。每个账号/每个窗口独立展示。

## 安全与请求边界

小组件刷新和读取账号只请求以下 GET，且拒绝重定向：

- `/api/v1/admin/accounts/:id`
- `/api/v1/admin/accounts/:id/today-stats`
- `/api/v1/admin/groups/all?include_inactive=true`

小组件不会调用模型、消耗推理 token、探测 Responses、刷新登录态、提交修改或触发额度重置。特意不使用通用 `/accounts/:id/usage`、批量 usage、OpenAI `/quota`：当前上游这些入口可能探测模型、清除账号异常或触发已配置的重置行为。Antigravity 的兼容 five_hour 字段也不代表真正 5 小时额度。

### 手动 Codex 重置：明确确认，一次请求

1. 先保存真实服务器设置。展开卡点「重置…」，或直接打开脚本的「Codex 重置中心」。链接中的账号 ID 仅为选择提示，绝不是批准。
2. 点「读取账号与重置券（只读）」。仅 OpenAI OAuth 主账号提供操作按钮；其他平台、API Key 账号和 Spark 影子账号不支持。缓存的券数不是实时资格承诺。
3. 点对应账号「核对并重置一次…」。应用重新 GET 账号详情，再显示明确的确认框：服务器、账号名/ID、缓存券数，**不可撤销地消耗 1 次 Codex 重置券**，可能恢复账号限流状态并刷新缓存。不能选择只清 5h 或只清 7d；实际重置窗口由服务端返回。
4. 只有点「消耗 1 次并重置」才执行。确认后再检查一次账号身份/类型。先把 pending 收据同步写入本机 Keychain 并读回验证，随后向你配置的 Sub2API 发送**一次** `POST /api/v1/admin/openai/accounts/:id/reset-quota`，无请求体，无窗口选择参数，无自动重试。所有上游交互由你的 Sub2API 服务器处理；脚本不直接连接 OpenAI。
5. 成功显示重置窗口数。即使缓存刷新/账号恢复部分失败，也明确表示重置已完成，不能再次点击来「修复」。超时、连接中断、5xx、格式不明都显示「结果不确定」，并保留本机防重复锁；券可能已经消耗。
6. 到管理后台核对实际结果。只有你确认「已核对，解除本机锁」，才允许以后发起新的确认；解除本机锁本身不发网络请求。成功操作也保留锁，防止误连点。

收据按服务器地址和账号 ID 绑定，换凭证/重新保存配置不会自动解除；移除管理凭证不会删除这些防重复收据。操作中的同步本机锁与 pending 收据可防止当前进程重复点击和常见重启重试，但**服务端不提供客户端幂等键**。不要在多个设备或多个独立运行实例同时操作同一账号；本工具无法提供跨设备锁或保证异常退出后的 exactly-once。

本版本只实现及模拟验证这个功能，未连接真实账号、未消耗任何实际重置券。不可把安装或小组件链接当作一次真实操作的批准。

管理员凭证只存设备专用、首次解锁后可访问的钥匙串项（`first_unlock_this_device`、不做 iCloud 同步），不会进入脚本源码、URL、小组件参数、普通配置、缓存、日志或安装包。网络异常不回显原始服务端响应。服务端详情响应可能包含敏感字段；只有白名单显示字段被归一化并缓存，原始账号对象不落盘。

重启后尚未首次解锁、钥匙串读取失败、401/403、离线和服务端错误都会降级为缓存或设置提示。不支持 HTTP、自签名证书绕过、URL 里的用户名密码或查询参数。不跟随重定向，避免把管理凭证发到其他地址。

「移除本机凭证和缓存」会切到演示模式。删除脚本也会删除脚本作用域内钥匙串项。新服务器必须重新输入凭证，不能沿用旧服务器的凭证。

## 刷新与兼容范围

默认请求约 20 分钟后刷新；iOS 自行决定真正刷新时间，不能保证准点或后台常驻。缓存减少重复请求。每次最多并行读取当前小组件可见的 1 / 2 / 4 个账号，小组件单请求超时 8 秒（应用内账号核对 12 秒，手动重置 45 秒）。失败保留每个账号的最后成功数据；不同尺寸/参数共享白名单缓存但独立检查所选账号的更新时间。

已依据 **Wei-Shaw/sub2api v0.2.15，commit `3a6fd1c9db07203ca308aaba69e502bc1f35b307`（2026-10-09）** 验证字段。兼容部署差异时采用「未提供」，不虚构数据。旧版没有当前 canonical Codex 字段时不推测 legacy primary/secondary 的意义。未配置或未观察到快照时，可通过正常业务使用让服务端自然采样，再等系统刷新；脚本不会主动制造使用量。

小组件的着色/强调模式可能由 iOS 覆盖背景和颜色。支持 standard systemSmall / systemMedium / systemLarge，锁屏/accessory family 未作适配。
